# Bitácora

App instalable (PWA) para tomar apuntes de texto y fotos desde el celular.
Los datos se guardan localmente en el dispositivo (IndexedDB), sin backend.

## Estructura
- `docs/` — código publicado (GitHub Pages sirve directo desde aquí)

## Desarrollo local
Abrir `docs/index.html` con Live Server o `python -m http.server` dentro de `docs/`.
